# Checklist de Homologacao

## API
- Login, refresh, logout e revogacao de dispositivo
- Consulta de perfil e dispositivos
- Rotas de laudo, inspecao, checklist, medicao, foto e nao conformidade
- Sincronizacao pull e push

## IA
- Salvamento de configuracao
- Cadastro de prompts
- Geracao assistida com log de uso
- Bloqueio por permissao

## Relatorios
- Tela de relatorios
- Exportacao CSV, XLS e PDF
- Impressao

## Dashboard
- Cards operacionais
- Resumo de API e IA
- Atividade recente

## Automacao
- Execucao no cron do sistema
- Log resumido de pendencias e vencimentos

## Seguranca
- Controle por permissao
- Validacao de payload
- Protecao de upload por MIME
- Token por dispositivo
